## 📖 Project Overview

This repository contains **five practical data analysis projects** developed as part of the **Professional Practice course of the Higher Technical Degree in Data Science at Teclab**.

The projects are based on the **Data Analysis with Python certification program by freeCodeCamp**, applying theoretical knowledge to practical problems involving statistical analysis, data manipulation, data cleaning, visualization, and predictive modeling.

Each project focuses on different aspects of data analysis using Python and its main scientific computing libraries.

The analyses cover several areas:

- Descriptive statistics and numerical calculations.
- Demographic characteristics and socioeconomic indicators.
- Medical data analysis and cardiovascular health indicators.
- Website traffic trends and time series analysis.
- Historical sea level measurements and predictive modeling.

Each project was developed independently, using Python to process datasets, perform calculations, and generate analytical results.

Additionally, an **interactive web portfolio was developed to centralize all five projects**, allowing visitors to explore their objectives, technologies, and original results through a unified interface.

# 🌐 Interactive Portfolio

A web-based portfolio was developed using **HTML5, CSS3, and JavaScript** to provide an interactive presentation of the five Python projects.

The portfolio offers a centralized dashboard where visitors can explore each analysis and visualize its original results.

### 🚀 Explore the Portfolio

**[View Data Analysis with Python Portfolio](https://melof10.github.io/data-analysis-with-python/)**

### Portfolio Features

- Centralized dashboard featuring all five projects.
- Individual project descriptions and objectives.
- Technologies used in each analysis.
- Interactive navigation between projects.
- Simulated analysis execution.
- Visualization of original Python-generated outputs.
- Detailed explanations of each result.
- Direct access to the original Python source code.
- Responsive design for desktop and mobile devices.
- Deployment through GitHub Pages.

### ▶️ Run Analysis

Each project includes a **Run Analysis** button that simulates the execution of the corresponding Python script.

When the button is clicked, the application:

1. Displays a simulated processing state.
2. Loads the original results generated by Python.
3. Renders the corresponding images.
4. Displays descriptions explaining the visualized results.
5. Provides access to the original Python implementation.

### Important Note

> **Precomputed Results:** The interactive portfolio displays results previously generated by the original Python analysis scripts.
>
> The **Run Analysis** button simulates processing and loads the saved outputs. Python code is not executed directly in the browser.
>
> All original freeCodeCamp project implementations, datasets, and unit tests remain unchanged.

This approach allows the portfolio to run entirely on **GitHub Pages**, without requiring a Python backend or additional hosting infrastructure.

### 📊 Descriptive Statistics with NumPy

# 🚀 Running the Portfolio Locally

The interactive portfolio can be executed locally using a simple HTTP server.

### 1. Clone the Repository

```bash
git clone https://github.com/Melof10/data-analysis-with-python.git
```

### 2. Navigate to the Project Directory

```bash
cd data-analysis-with-python
```

### 3. Start a Local Server

Using Python:

```bash
python3 -m http.server 8000
```

### 4. Open the Browser

```text
http://localhost:8000
```

The main portfolio page provides access to all five projects.

### 5. Explore the Results

1. Select a project from the dashboard.
2. Review its description and technologies.
3. Click **Run Analysis**.
4. Wait for the simulated processing to complete.
5. Explore the original Python-generated results.
6. Click **View Python Source** to inspect the implementation.

> The interactive portfolio runs entirely in the browser. A Python backend is not required to display the precomputed results.
